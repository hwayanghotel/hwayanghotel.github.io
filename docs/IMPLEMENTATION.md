# 구현과 검증 기록 — 새 디자인 2차

2026-10-03. 새로 선정한 숙박·식당 벤치마크를 실제 능운대 사진과 내용에 적용했습니다. 기존 미색·마루부리·분할 첫 화면은 교체했습니다. 디자인 문서, 벤치마크 캡처와 전체 원본 아카이브는 별도 로컬 작업 폴더에 보존했습니다. 이 문서의 `artifacts/` 경로는 로컬 검증 산출물이며 저장소에는 포함하지 않습니다.

## 변경한 화면

홈은 계곡 전폭 사진, 숙박·식사·방문 링크, 실제 펜션 외관, 네 객실, 산책 사진, 음식 사진, FAQ로 구성했습니다. PC 대표 사진은 A166, 모바일은 A141로 구분했습니다. 처음 선택했던 A061은 잎이 화면 대부분을 차지해 최종 대표 사진에서 제외했습니다.

식당과 계곡 페이지도 사진으로 시작하도록 재구성했습니다. 객실은 사진과 사실 정보를 우선하고, 오시는 길과 이용 안내는 새 흰 배경·고딕·여백 체계에 맞췄습니다. 섹션 제목, 버튼, 메뉴, 모바일 예약 영역을 전체 페이지에 일관되게 적용했습니다.

제목과 본문은 로컬 Pretendard 단일 서체입니다. 기본 배경은 #FFFFFF, 글자는 #1B201E입니다. 마루부리 서비스 파일을 이전 자료로 옮겼습니다. 보유 사진 25개에 출처를 유지하고 크기별 WebP를 생성합니다. 넓은 사진을 모바일 세로 배너에 사용할 때 화면 너비만으로 작은 이미지를 선택해 흐려지던 문제를 수정했습니다.

## 실행한 최종 검증

- `npm run check`: 오류·경고·힌트 0. 로그 `artifacts/type-check.log`.
- `npm run build`: 정적 빌드 성공. 로그 `artifacts/build.log`.
- `npm test`: 41개 통과, PC에 해당하지 않는 모바일 메뉴 검사 1개 제외. `artifacts/test-run.log`, `artifacts/test-results.json`.
- `scripts/audit-site.mjs`: 주요 10페이지 × PC·모바일 20화면, 가로 넘침·이미지 로드 오류·브라우저 실행 오류 0. `artifacts/site-audit.json`, `artifacts/site-audit.log`.
- JavaScript 없이 메뉴·객실 이동·사진 원본 링크·FAQ·주소 읽기 가능. 복사 버튼은 JavaScript가 없을 때 숨김. 200% CSS 확대에서 가로 넘침 없음.
- `scripts/capture-redesign.mjs`: 7개 대표 경로의 첫 화면·전체 화면, PC·모바일 총 28장. 이미지 디코딩 후 캡처하여 늦게 읽힌 사진이 비어 보이지 않도록 확인. `artifacts/redesign-review.json`.
- 서비스 공통 JS: 2,561바이트, gzip 1,152바이트. 전체 배포 파일 198개, 16,696,519바이트.
- 로컬 390px/DPR 1 홈 초기 리소스 약 670KB. HTML 본문을 제외한 수치이며 실사용 네트워크 속도나 Core Web Vitals 측정이 아님.

미리보기는 http://localhost:4321 입니다. `dist/`와 동일한 파일을 정적 미리보기로 제공합니다. 전체 페이지 캡처의 고정 예약 영역은 촬영 시 최초 뷰포트 위치에 보이며 실제 사용 중에는 화면 하단에 고정됩니다.

## 범위와 남은 운영 단계

실제 고객용 예약 제출·결제·전화 통화는 수행하지 않았습니다. 모바일은 Chromium 에뮬레이션이며 iOS Safari·Android 실제 기기의 지도·전화 앱 전환은 별도입니다. 구형 객실 원본의 해상도 한계는 재촬영으로 개선해야 합니다.

2026-10-05 배포 구성에서는 제공된 GitHub 저장소의 Angular 소스를 현재 Astro 프론트로 교체하고 기존 `gh-pages` 게시 방식을 사용합니다. canonical·OG·사이트맵은 `https://hwayanghotel.github.io`를 가리킵니다. 기존 운영 도메인과 DNS는 변경하지 않습니다. 배포 방법은 [배포 안내](DEPLOYMENT.md)에 정리했습니다. 이전 구현본과 검증 기록은 로컬 아카이브에 보존했습니다.
